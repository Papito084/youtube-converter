# 🎵 YouTube to MP3/MP4 Converter

Una aplicacin web backend desarrollada en Python (Flask) diseada para descargar y convertir rpidamente videos de YouTube a formatos de audio (MP3) y video (MP4) de alta calidad sin publicidad invasiva ni lmites.

## 🚀 Caractersticas
- **Alta Velocidad y Fiabilidad:** Utiliza el potente motor `yt-dlp` (el estndar de la industria) junto a `ffmpeg` para extracciones extremadamente rpidas y seguras.
- **Formatos Soportados:** Conversin directa a MP3 (solo audio) y MP4 (Video).
- **Interfaz Web Limpia:** Muy fcil de utilizar: simplemente pega el link del video de YouTube, elige el formato y descarga.
- **Descargas Locales y Privadas:** Guarda los archivos convertidos directamente en tu mquina local evitando los clsicos servicios web llenos de pop-ups maliciosos.

## 🛠️ Instalacin y Uso (Windows)
Requisitos previos: Necesitas tener Python instalado en tu sistema.

1. Clona el repositorio.
2. Instala las dependencias necesarias abriendo una terminal en la carpeta:
   ```bash
   pip install flask yt-dlp imageio-ffmpeg
   ```
3. Ejecuta la aplicacin haciendo doble clic en el archivo proporcionado `Launch YouTube Converter.bat` o desde la terminal ejecutando `python app.py`.
4. La aplicacin web se abrir automticamente (por defecto en `http://localhost:5000`).
5. Pega la URL del video y descarga.
